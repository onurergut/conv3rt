conv3rt — Third-Party Notices
=============================

This build currently links only against Apple system frameworks:

  - Foundation, AppKit, SwiftUI, CoreGraphics, ImageIO, CoreImage, PDFKit,
    UniformTypeIdentifiers, CoreText

These are part of macOS and are not redistributed with conv3rt. No third-party
source code is compiled into this build.

Apple system frameworks are used under the terms of the macOS SDK license
agreement.

-------------------------------------------------------------------------------
Bundled third-party codecs
-------------------------------------------------------------------------------
None yet. WebP/AVIF/JPEG XL are READ-ONLY with the native Image I/O back end on
this macOS version. Writing those formats is not implemented, so those formats
are not offered as output targets and no third-party codec is bundled.

If a bundled codec is added later, its name, pinned version, source URL,
license and the exact files copied into the bundle will be listed here, and the
license text will be placed in Contents/Resources/.

-------------------------------------------------------------------------------
Test fixtures
-------------------------------------------------------------------------------
All test images are generated programmatically at runtime (see
Tests/Conv3rtCoreTests/Fixtures.swift). No third-party test images are stored in
this repository, so there are no external fixture licenses to track.
